TRANSCRIPTS: SUNRISE CLINIC FRONT DESK AGENT

Every conversation below was produced by running the agent in this repository.
Caller turns, tool calls, tool results, agent replies and outcomes are copied from
those runs; none were written by hand. Lookup results are trimmed to id, name, phone,
guardian_of and booked appointments.

How to read one conversation:
  CALLER       what the caller said, in order.
  SAFETY       the keyword screen in safety.py, which runs on every turn before
               anything else. The model can add a flag but cannot remove one.
  TOOL CALL    a tool the Python policy called, shown at the point where it fired.
  TOOL RESULT  what the tool returned. Every fact in a reply comes from here.
  AGENT        a template filled with tool results. The model never writes it.
  FINAL OUTCOME the fields POST /agent/run returns.

Reads (lookup_patient, search_slots) happen while the caller talks. The one write
(book / reschedule / cancel) happens only after the last turn.

Not shown: the structured reading of each turn (intent, doctor, dates, time, names).
The application does not expose it in its transcript, so it is left out here.
